# RuteX Go 🏛️📱

> Aplicación móvil gamificada para turismo cultural en Extremadura

[![GitHub Issues](https://img.shields.io/github/issues/Rutex-Go/rutex-go-project.svg)](https://github.com/Rutex-Go/rutex-go-project/issues)

## 📋 Descripción del Proyecto

RuteX Go es una aplicación móvil gamificada diseñada para transformar el turismo en Extremadura. Permite recorrer monumentos y espacios culturales mediante rutas interactivas con trivias, retos y logros, combinando cultura, ocio y educación.

## 🎯 Objetivos

- ✅ Ofrecer una experiencia turística innovadora y gamificada
- ✅ Potenciar la valoración del patrimonio cultural extremeño
- ✅ Integrar dinámicas educativas para turistas de todas las edades
- ✅ Impulsar el comercio local mediante recompensas
- ✅ Promover la sostenibilidad y alineación con los ODS 2030

## 🛠️ Tecnologías

- **Frontend:** Flutter/Dart + Android (Kotlin/Java)
- **Backend:** Firebase (Auth, Firestore, Storage, Messaging)
- **Base de Datos:** Firestore (NoSQL)
- **Geolocalización:** Google Maps API
- **Herramientas:** Android Studio, VS Code, GitHub
