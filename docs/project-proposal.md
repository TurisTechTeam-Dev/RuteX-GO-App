## Descripción del Proyecto

RuteX Go es una aplicación móvil gamificada diseñada para transformar el turismo en Extremadura. Permite recorrer monumentos y espacios culturales mediante rutas interactivas con trivias, retos y logros. Se combina cultura, ocio y educación, fomentando además el comercio local y el turismo responsable.

## Justificación y Objetivos

### Objetivos Principales
- Ofrecer una experiencia turística innovadora y gamificada
- Potenciar la valoración del patrimonio cultural en Mérida y otras ciudades extremeñas
- Integrar dinámicas educativas para turistas de todas las edades
- Impulsar el comercio local mediante recompensas y promociones
- Promover la sostenibilidad y alineación con los ODS 2030

### Objetivos Específicos
- Desarrollar una aplicación móvil multiplataforma funcional
- Implementar un sistema de geolocalización preciso para rutas culturales
- Crear un motor de gamificación con trivias, retos y logros
- Integrar servicios de Firebase para autenticación y almacenamiento
- Diseñar una interfaz de usuario intuitiva y accesible

## Contenidos y Aspectos Principales

La aplicación incluye:
- Sistema de registro y autenticación de usuarios
- Rutas culturales con geolocalización GPS
- Trivias interactivas sobre patrimonio cultural
- Sistema de retos y desafíos gamificados
- Logros desbloqueables y sistema de puntuación
- Rankings y competiciones entre usuarios
- Futuras integraciones con comercios locales
- Soporte multilenguaje (español, inglés, portugués)

## Tecnologías y Herramientas

### Desarrollo
- **Lenguajes:** Kotlin/Java (Android), Flutter/Dart
- **Base de Datos:** Firestore (NoSQL)
- **Backend:** Firebase (Auth, Firestore, Storage, Messaging)
- **Geolocalización:** Google Maps API
- **Herramientas:** Android Studio, VS Code, GitHub
