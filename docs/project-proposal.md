## Descripción Ejecutiva del Proyecto

RuteX Go es una aplicación móvil gamificada desarrollada por TurisTech Team que transforma la experiencia turística en Extremadura mediante rutas culturales interactivas. La aplicación combina patrimonio histórico, tecnología moderna y elementos de juego para crear una experiencia educativa única que permite a los usuarios explorar monumentos, participar en trivias culturales y desbloquear logros mientras descubren la riqueza histórica de la región.

El proyecto se centra inicialmente en Mérida como ciudad piloto, aprovechando su excepcional patrimonio romano y su designación como Patrimonio de la Humanidad por la UNESCO, para posteriormente expandirse a otras ciudades extremeñas como Cáceres, Plasencia y Badajoz.

## Justificación del Proyecto

### Contexto y Necesidad
Extremadura posee un patrimonio cultural excepcional que incluye dos ciudades Patrimonio de la Humanidad (Mérida y Cáceres), numerosos monumentos históricos y un rico legado que abarca desde la época romana hasta el renacimiento. Sin embargo, la experiencia turística tradicional no aprovecha completamente las posibilidades que ofrecen las nuevas tecnologías para crear experiencias inmersivas y educativas.

### Problema Identificado
- **Desconexión generacional:** Los jóvenes muestran menor interés por el turismo cultural tradicional
- **Experiencia pasiva:** Los visitantes consumen información sin participación activa
- **Falta de gamificación:** Ausencia de elementos motivacionales y competitivos
- **Limitada integración digital:** Pocos recursos tecnológicos en la experiencia turística
- **Impacto económico limitado:** Escasa conexión entre turismo cultural y comercio local

### Oportunidad de Mercado
- Crecimiento del turismo experiencial y tecnológico
- Auge de las aplicaciones de gamificación educativa
- Apoyo institucional al turismo cultural en Extremadura
- Demanda de herramientas digitales post-pandemia
- Alineación con los Objetivos de Desarrollo Sostenible (ODS 8, 11, 12)

## Contenidos y Funcionalidades Principales

### Módulo de Autenticación y Gestión de Usuarios
- **Registro y autenticación** con Firebase Authentication
- **Perfiles de usuario personalizables** con avatar y preferencias

- **Catálogo de rutas temáticas** (romana, medieval, renacentista, contemporánea)

- **Información contextual** sobre monumentos y espacios culturales

- **Trivias interactivas** específicas para cada monumento visitado
- **Sistema de puntuación** progresivo con bonificaciones por precisión
- **Logros desbloqueables** organizados por categorías temáticas
- **Insignias coleccionables** representando diferentes épocas históricas
- **Desafíos especiales** temporales y eventos culturales

- **Rankings globales** de todos los usuarios de la plataforma
- **Clasificaciones regionales** por ciudades y provincias
- **Competiciones semanales/mensuales** con temáticas específicas
- **Comparación con amigos** y círculos sociales
- **Historial de logros** y progreso personal detallado

### Contenido Educativo y Cultural
- **Base de datos completa** de patrimonio extremeño
- **Contenido multimedia** (imágenes HD, videos, audio-guías)
- **Información histórica contextualizada** por épocas y estilos
- **Curiosidades y datos interesantes** sobre cada monumento
- **Conexiones históricas** entre diferentes lugares y épocas

### Integración Comercial y Social
- **Sistema de recompensas** canjeables en comercios locales
- **Descuentos y promociones** en restaurantes, tiendas y servicios
- **Mapa de comercios colaboradores** cercanos a rutas turísticas
- **Reseñas y recomendaciones** de otros usuarios
- **Compartir logros** en redes sociales

### Características Adicionales
- **Soporte multiidioma** (español, inglés, portugués)
- **Modo offline básico** para consultar rutas descargadas
- **Notificaciones push inteligentes** sobre proximidad y eventos

## Tecnologías y Herramientas de Desarrollo

### Stack Tecnológico Principal

#### Frontend Móvil
- **Android Nativo:** Kotlin/Java con Android SDK 24+
- **Framework UI:** Jetpack Compose para interfaces modernas
- **Arquitectura:** MVVM (Model-View-ViewModel) con LiveData
- **Navegación:** Navigation Component con Safe Args
- **Inyección de dependencias:** Hilt/Dagger para modularidad

#### Backend y Servicios Cloud
- **Backend as a Service:** Firebase Suite completa
  - **Authentication:** Gestión segura de usuarios y sesiones
  - **Firestore:** Base de datos NoSQL escalable y en tiempo real
  - **Storage:** Almacenamiento de multimedia (imágenes, videos)
  - **Functions:** Lógica de servidor para operaciones complejas
  - **Analytics:** Métricas de uso y comportamiento de usuarios
  - **Crashlytics:** Monitorización de errores y estabilidad

#### APIs y Servicios Externos
- **Google Maps API:** Geolocalización, mapas y navegación
- **Places API:** Información adicional sobre puntos de interés
- **Directions API:** Cálculo de rutas optimizadas entre puntos
- **Geocoding API:** Conversión entre coordenadas y direcciones

#### Herramientas de Desarrollo y Productividad
- **IDEs:** Android Studio (principal), Visual Studio Code (documentación)
- **Control de versiones:** Git con GitHub para colaboración
- **CI/CD:** GitHub Actions para integración y despliegue automático
- **Testing:** JUnit, Espresso para pruebas unitarias e integración
- **Documentación:** Markdown, Javadoc para código
